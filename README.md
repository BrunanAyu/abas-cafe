# AB-AS Cafe

A responsive website for AB-AS Cafe in Arada, Dessie, Ethiopia.

## Features

- Cafe information, photo gallery, and customer reviews
- Featured dishes and a full menu with ETB prices
- Reservation request form that prepares an SMS
- Contact details and opening hours

## Run locally

Open `index.html` in a web browser. The menu and gallery use local assets from the `images/` directory.
